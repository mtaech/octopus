Q1 叙事演出形态（多模板）

三种演出模板并存、可随时切换：A 聊天流 / B 剧本式 / C 沉浸式视觉小说——同一场戏、同一回合模型，仅呈现层不同；顶栏 🎭 或底栏 ←→ 切换（默认聊天流）。

Q2 布局骨架

单栏叙事为主舞台；面板走抽屉/边栏且形态各不同：A 右侧演员卡 + 地图/日志右抽屉；B 左侧角色表 + 剧本旁批注；C 顶部 HUD + 底部文本框，演员卡为悬浮小面板。

Q3 确认门

机制动作 = 流内挂起确认卡片（拟执行动作 + 后果 + 确认/取消，确认后原位变结算结果）；顶栏「免确认」可全局开关。

Q4 元指令

同一输入框 / 前缀 + 常驻快捷按钮（切换角色 / 存档 / 重来）。

Q5 角色状态

常驻紧凑演员卡（关键属性/资源/状态，点开全表）；NPC 在场时轻量出现。

Q6 流式与等待

就地打字机 + 可跳过；管线阶段徽标（主线思考中 → 角色回应中 → 结算中）。判定卡呈现跟随故事书声明的判定器（本演示故事书为 d20 风格参数）。
