Q1 页面组织

A 分区并置：顶部动作带（继续游玩 / 新建 / 导入）+ 故事书网格 + 存档列表，自上而下三区。 B 卡片流混合：单一滚动流按时间混合两类卡片。 C 侧栏分栏：左导航两列表 + 右工作区详情。

Q2 卡片内容与操作

故事书卡 = 标题 / 版次 / 发布态 + 新建游戏 · 进编辑器。存档卡 = 标题 / 故事书名 / 时间 / 需升级角标 + 继续游玩 · 升级入口；管理操作（升级向导 / 新原点 / 分享）折叠或全部进游玩页抽屉。

Q3 空态与引导

无故事书 → 引导去编辑器新建；无存档 → 引导新建游戏 / 导入。

Q4 与游玩页抽屉的关系

本页是否只做入口直达（继续游玩 / 新建 / 导入），存档管理全部进游玩页抽屉（#21），还是从列表页留「管理」入口深链进抽屉？

Q5 进入流程

新建游戏 = 直接开档进游玩页（B）还是先选书 + 起名确认（A / C）？「继续游玩」对需升级存档 = 直达（B）还是先出提示中间态（C）？
