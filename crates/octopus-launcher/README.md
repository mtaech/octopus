# Octopus 启动器（octopus-launcher）

一个基于 GPUI Kit 的原生桌面启动器，用来启动、停止与观察 Octopus 的本地服务。它是 `start.sh` 的图形化等价物，但用原生窗口而不是终端。

## 运行

```bash
cargo run -p octopus-launcher
```

## 当前能力

- **状态卡片**：后端（octopus-bin / axum，127.0.0.1:8787）与前端（Vite，127.0.0.1:5173）各一张，实时显示运行中 / 启动中 / 停止中 / 已停止 / 已退出。
- **启动与停止**：支持单独启动/停止，也支持「全部启动 / 全部停止」。
- **外部进程识别**：通过端口探测判断，即使服务是用 `./start.sh` 在别处启动的，也能识别为运行中。
- **日志**：把后端与前端的 stdout/stderr 收进有上限的环形缓冲并合并显示；无输出时给出空态提示。
- **打开网页**：用系统默认浏览器打开前端地址。

## 实现要点

- `main.rs`：GPUI 视图与交互（状态卡片、日志面板、底部操作栏）。
- `services.rs`：与 UI 无关的进程管理 —— 端口探测、子进程启动（独立进程组）、整组终止、日志读取、打开浏览器。
- 后端用 `cargo run -p octopus-bin` 启动；前端按 pnpm → npm → bun → yarn 的顺序选择包管理器。
- 子进程用独立进程组启动，停止时向整组发 SIGTERM，避免 pnpm/cargo 的子进程残留。
