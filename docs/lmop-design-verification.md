# LMoP 真实剧本核对报告

> 触发：拿 `story_example/凡戴尔的失落矿坑.md`（凡戴尔的失落矿坑，完整 D&D 5e 冒险模块）
> 反过来核对三份设计——判定 / 图鉴 / 地图与剧情。
>
> 结论先行：**三份设计都漏了主干机制**。根本原因是同一个——我把「引擎必须求值」当作升格判据，
> 却把「**在真实剧本里高频出现**」误当成「可以后置」。优势/劣势 25 处、被动 36 处、豁免 39 处、
> 突袭 25 处、经验值 85 处——这些不是边缘特性，是主干。

## 一、判定设计：漏了 D&D 最高频的机制

### 1. 优势 / 劣势（25 处）——设计里一个字都没有

真实用法：

- 「消耗激励可使该角色在一次**属性检定、攻击检定或豁免检定**中获得优势」（第 132 行）
- 「**黑暗忠诚**：邪教徒为抵抗魅惑和恐慌而进行的豁免检定具有优势」（2666）
- 「**日照敏感**：在阳光下，邪灵在攻击骰上处于劣势，并且在依赖视力的感知（察觉）检定上也处于劣势」（3128）
- 「**集群战术**：狼至少有一个未处于失能的盟友在目标生物5尺内时，它对该生物发动的攻击检定有优势」（3700）
- 「**伏击**：战斗开始的第一轮里，变形怪对任何成功受其突袭的生物所发动的攻击检定具有优势」（2711）

**实现要求**：
- 掷两次取高（优势）/ 取低（劣势）——引擎必须求值
- **按判定类别分别生效**：属性检定 / 攻击检定 / 豁免检定（D&D 把它们当三类）
- 来源可以是状态（激励）、挂接定义（怪物特性）、条件（日照、集群）

**引擎现状**：`crates/octopus-types/src/lib.rs` 里 `advantage` / `disadvantage` **零命中**。
`CheckerDef` 没有该字段，`ResolvedCheck` 也没有预留。

→ 必须补进判定设计 C1（字段）与 C4（掷骰实现）。

### 2. 被动值不只用于「自己不掷骰」，还用作**对抗的另一方**（36 处）

- 「将该结果与角色的**被动感知（察觉）属性值**进行比较」（195）
- 「让每个前进的角色进行一次敏捷（隐匿）检定，**与地精的被动感知（察觉）属性值对抗**」（309）
- 「每个角色可以尝试进行一次敏捷（隐匿）检定来**对抗地精的被动感知（察觉）属性值**」（370）
- 「若地精的敏捷（隐匿）检定**超过**可能注意到其移动的任何角色的**被动感知（察觉）属性值**，则地精的行动不会被察觉」（350）

→ 对抗有**三种组合**：掷 vs 掷 · 掷 vs 被动 · 被动 vs 掷。
我的判定设计 §5 只设计了「掷 vs 掷」；`CheckKind::Passive` + `passive_base` 只够算**自己的**被动值。

### 3. 豁免成功 = **伤害减半**，不是「完全不生效」

- 「任何生物必须成功通过DC 10的敏捷豁免检定，**否则**会受到坠落瓦砾造成的3d6钝击伤害（**成功通过豁免则伤害减半**）」

**引擎现状**（`crates/octopus-engine/src/command.rs:303-306`）：
```rust
let effect_applies = match (&check, checker_kind) {
    (Some(resolved), CheckKind::Save) => !resolved.result,   // 成功 = 效果不结算
    _ => true,
};
```
→ **豁免成功 = 效果完全不结算**，与「减半」差一档。

需要「部分成功」的表达：`EffectDef` 加 `on_save?: 'none' | 'half' | 'full'`。

### 4. 状态需要「每回合末重复豁免」与「专注」

- 「否则在攻击检定、豁免检定和属性检定上获得劣势，持续1分钟。生物可以在**其每回合结束时重复进行豁免检定**，若成功则提前终止效应」（4 处）
- 「变形怪只要保持**专注**就可以持续阅读思想（如同专注一个法术）」（5 处专注）

**引擎现状**：`StatusDef` 只有 `duration` + `unit: turns|scenes` + `stack` + `effect`。
**没有**：重复豁免（DC + 属性 + 成功即结束）、专注（受击打断）、「1 分钟」这类单位。

### 5. 条件性检定修正——不是静态属性加值

「日照敏感」「敏锐视觉」「集群战术」「岩地伪装」「伏击」「魔法抗性」都是**带条件的、作用于特定判定类别**的修正。

**引擎现状**：`AttributeModifier { attribute, value }` 是**静态属性增量**；
`EffectDef.modifiers` 也只是技能使用瞬间的属性加值。
→ 缺 `ConditionalModifier { applies_to, condition, op, value }`（`op` 含 advantage / disadvantage）。

### 6. 熟练加值给不出来（与 CONTEXT.md 的既定决策冲突）

- 「查阅附录 B 中的地精资料卡。由于地精们正在躲藏，你需要知道它们的**隐匿技能调整值：+6**」（194）

`CONTEXT.md:338` 说熟练项「**应作为开放内容挂接**」。
但开放内容挂接目前只能通过 `modifiers` 给**属性维度 / 派生值**加值——
**给不了「隐匿检定 +6」**。既定决策与实现能力之间有缺口。

### 7. 突袭（25 处）被我后置了

- 「任何属性值低于地精检定结果的角色将突袭，并在**战斗第一轮**失去其回合」（195）

核对后：突袭**不需要完整先攻系统**，但需要「战斗第一轮」这个标记。
25 处的高频说明它不该躺在后置清单里。

## 二、图鉴设计：漏了继承，错判了 XP

### 8. 数据卡继承 / 变体——完全没有设计

- 「这些丧尸……它们**使用丧尸资料卡，并具有以下额外特性**」（1433 / 2541）——灰烬丧尸 = 丧尸 + 特性
- 「若需要数据，**使用平民数据卡**来代表任何种族的成年通用角色」（582）

变体怪在真实规则书里是标准做法。我的图鉴条目只能是独立完整的。
→ 缺 `extends?: string`（继承 + 覆盖 / 追加）。
没有它，LMoP 图鉴要手抄 30 条完整数据卡，且丧尸与灰烬丧尸的重复无法收敛。

### 9. XP 是引擎要**合计**的，不是展示型

- 「每个怪物的经验值在其数据卡中注明。你通过**合计角色们克服的每个怪物的经验值**来计算奖励」（1987）
- 全篇「经验值」85 处

我在图鉴 §3.2 把 `challenge` / `xp` 判为「引擎不读」——**核对后这是错的**。
击败的怪物要能累加 XP（到角色资源或 flag），属于「引擎要读写」。

### 10. 伤害类型 / 免疫：我的判断是循环论证

- 「**伤害免疫** 毒素」「**状态免疫** 中毒」（2558-2559），全篇免疫 23 处

我在图鉴 §3.2 的理由是「无伤害类型概念」——但这是**循环论证**：
没有概念所以不做，不做所以没有概念。

诚实的结论应该是：**明确承认 v1 的简化**（单一 hp 血条、伤害是无类型数字），
把「伤害类型」登记为**待评估的封闭新概念**，而不是塞进 `statblock` 展示文本里假装解决了。

## 三、地图与剧情：漏了「遭遇表」

### 11. 随机遭遇表（rollable table）——机制完全缺失

- 「在白昼和黑夜各进行一次遭遇检定，通过掷一枚d20骰子。若骰出17-20点，则会发生一次遭遇。
  **再掷一枚d12骰子并查阅野外遭遇表格**来确定队伍会遇到什么」（1221）
- 「掷一枚d12并查阅**游荡怪物表格**来决定队伍会遇到什么」（1993）

我的 P5「触发点预置遭遇」只能表达**固定遭遇**，表达不了「掷表决定」。
→ 需要「遭遇表」概念，形状大致是 `{ die, trigger_on, entries: [{ min, max, preset }] }`。
这正是 LMoP「游荡怪物」章节的原样结构。

### 12. 地点 / 场景 / 地图的规模——这部分设计成立 ✅

- 附录 B 有 30 个怪物条目；正文有几十个「第 N 区」，每个区域就是一处地点 + 一场戏
- 「凡达林」「三猪小径」「回声洞」「飞龙突岩」是地点，「第 1 区」…「第 14 区」是子地点
  → **地点树 `parent_id` 够用**（回声洞 > 第 5 区）
- 剧本同时提供「区域地图」与「地牢地图」→ **确认了「一个地点多张图」的判断是对的**

### 修订后的优先级判断

原先我按「引擎是否必须求值」排序，漏掉了「真实剧本里出现多少次」这个维度。
两个维度合起来看，**判定设计的 C1/C2 之后应该紧接着补优势/劣势与豁免减半**——
它们不是 C4 的「锦上添花」，而是让规则集能跑起来的前提：

| 期 | 新增内容 |
|---|---|
| **C1**（数据模型） | + `advantage`/`disadvantage` 字段 · + `on_save` · + `ConditionalModifier` · + `save_ends` |
| **C2**（一个内核） | 不变 |
| **C2.5**（新） | **优势/劣势掷骰** · **豁免减半** · **被动值作为对抗方** |
| **C3** | 对抗（含掷 vs 被动） |
| **C4** | 骰面特殊 · 成功度外露 · `modifier_formula` |
| **图鉴 M1** | + `extends`（继承） · XP 改为引擎读写 |
| **P5** | + `EncounterTable`（掷表遭遇） · + 战斗第一轮标记（突袭） |
